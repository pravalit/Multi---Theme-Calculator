# Multi Theme Calculator

A responsive calculator built using:

- HTML5
- CSS Variables
- JavaScript State Management
- LocalStorage

## Features

✔️ Dark Theme

✔️ Light Theme

✔️ Neon Theme

✔️ State Management

✔️ Theme Persistence

✔️ Responsive UI
